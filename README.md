# SimplifyNext-2026-Agentic-AI-Hackathon
# NUS Life OS

## First Use Case

Help an NUS student get an AI internship by graduation.

## Input

- Year / major
- Modules taken
- Skills
- Projects
- Experience
- Career goal
- Graduation date

## Agent Job

Given the student's current state and goal:

1. Identify the biggest gaps.
2. Create a prioritized plan.
3. Explain why each action matters.
4. Decide what should happen next.

## First Test

Student:
- Year 2 Computer Science
- CAP 4.2
- Python
- Machine Learning
- 2 ML projects
- No internship
- Goal: AI/ML internship next summer

Expected:
The agent should produce a concrete plan for the next 3 months.
